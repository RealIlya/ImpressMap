# ImpressMap

## Description

The application allows the user to have discussions on the topic of landscaping the certainty of 
the territory.

## Main features

### Markers on map info

Users authorized in the application can **select** residential addresses from a list (maximum 5),
the labels of which will subsequently be displayed on the map in the selected area.

### What can you do with selected addresses?

1. Among the displayed addresses, you can **click on one**, making it *active*.
2. In the *active* address area, you can create labels with some information in the post.

### Commenting

* Posts can be commented on.
* Comments can be commented on.
* You can create entire discussion threads.
